# 赚了么

## Platform
web

## Users and purpose
小型零售及餐饮店经营者。按店铺维护持续保存的利润成本账本，通过手动录入，或在 AI 对话内核对确认卡片后立即入账；进入店铺先显示欢迎面板；打开店铺子菜单中的经营总览或账目明细后，数据与官方 AI 对话同时可见。

## Confirmed constraints
使用用户提供的赚了么 Logo。店铺映射到 DSH 工作区，每店多会话共用账本。采购不等于耗用成本；金额用整数分计算；缺失不当作零；人工确认 AI 草稿后才成为账目。第一版是当前本地 DSH 实例的账本，不宣称 SaaS 多租户权限、库存或完整会计系统。

## Reference
参考相邻 zhuanleme/agent-core/docs/ury-analysis.md 与本地 ury-reference 的业务概念，独立实现，不引入 URY 源码和运行依赖。

## 当前体验
零售演示店「青禾生活」包含虚拟七天销售、采购与成本记录；演示店与真实店铺按工作区隔离，并在报告中标记 demo。总览使用流水与成本叠加柱、利润折线组合图与成本环形图；明细使用 Material React Table 切换收入／支出表，支持搜索、排序、单元格录入修改及 Excel / CSV 导出；AI 草稿通过对话确认。

## 对话与核对
店铺对话支持归档、取消归档、移至已删除及恢复，并可搜索和展开更早历史。删除为可恢复移除，不擦除原始对话或经营账本。AI 新增账目、修改/撤销账目和成本规则均在对应对话中显示确认卡片；卡片显示当前店铺、日期、金额、修改前后内容和处理状态。确认直接生效，账表同步更新。

## 店铺项目与直接记账
每店对应本地项目文件夹；经营总览、账目明细和智能经营是同级入口。智能经营默认收起，展开后直接显示各个聊天，最右侧加号新建本店对话；归档与已删除对话从标题更多菜单进入独立管理窗口。店铺和智能经营分别可折叠；最近对话悬停显示归档和更多操作，置顶位于浮动菜单中并持久保存。账目明细以按钮切换收入表和支出表，营业收入归收入、采购及实际成本归支出；桌面列为营业日期、发生时间、项目、金额、渠道或类型、操作；手机优先项目和金额。点击无框编辑并自动保存，Esc 取消；删除常显居中，可从持久历史恢复。新增为表内无框录入，工具栏保留简短新增入口，成本规则不占据明细界面。更多菜单提供历史、期间报表、日结、备份和可选业务字段。账本仍在本地 Profile SQLite 内按店隔离。
